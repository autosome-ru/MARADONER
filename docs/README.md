# MARADONER-doc

Запуск `compile.py` собирает документацию.
```
>python3 compile.py
```

## Где чё
В папке `content` подпапки, соответствующие большим кнопкам в горизонтальном меню. В них - текстовые файлы с HTML-разметкой, соответствующие пунктам в левом меню. Файлы и метаданные описаны в соответствующих `info.json` файлах в каждой из папок.

В `template.html` шаблон всех страниц. В `template_menu.html` шаблон центрального меню. В `template_menubutton.html` шаблон кнопки в меню.

Собранные страницы (`index.html`, `faq.html`, `contact.html`, `cite.html`, `tutorial/*.html`, `sitemap.xml`) перезаписываются при каждом запуске, руками их править незачем.

## Requirements
```
> pip install htmlmin2
```
Без `htmlmin` страницы собираются без минификации. Оригинальный `htmlmin` не ставится на свежий Python (3.13+), `htmlmin2` - его форк с тем же именем модуля.
